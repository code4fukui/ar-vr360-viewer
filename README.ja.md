# AR/VR 360度ビューアー

このプロジェクトは、Webブラウザでパノラマ画像の表示、AR/VR表示、キーボードやマウスによる操作に対応した360度ビューアーを提供します。

## デモ
https://code4fukui.github.io/ar-vr360-viewer/

## 機能
- 360度パノラマ画像の表示
- AR/VR表示に対応
- キーボードやマウスによる操作

## 必要環境
Webブラウザとインターネットへの接続が必要です。

## 使い方
ページURLにパノラマ画像のURLをカンマ区切りで指定すると、複数の画像を表示できます。
例: https://code4fukui.github.io/ar-vr360-viewer/#https://img.fukuno.com/vr180/20240819_jigintern/R0030142.JPG,https://img.fukuno.com/vr180/20240819_jigintern/R0030143.JPG
