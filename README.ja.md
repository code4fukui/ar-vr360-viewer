## デモ
https://code4fukui.github.io/ar-vr360-viewer/

## 機能
- 360度パノラマ画像を表示します
- 単一または複数の画像をサポートします
- キーボードとマウスでカメラ操作が可能です
- Three.jsを使ってブラウザ上で動作します

## 要件
Webブラウザとインターネット接続。

## 使用法
ビューアを実行するには、単に `index.html` ファイルをウェブブラウザで開くだけです。URLハッシュフラグメントにコンマ区切りの1つ以上の画像URLを渡すことができます。例: `index.html#https://example.com/image1.jpg,https://example.com/image2.jpg`.
